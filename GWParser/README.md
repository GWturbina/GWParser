# Поиск контактов GlobalWay (GWParser)

Программа для Windows: находит в открытых Telegram-группах людей, которые сами
пишут, что им что-то нужно, и передаёт их в «Поиск клиентов» клуба на cgift.club.
Программа никому ничего не пишет и ничего не публикует - только читает.

Скачать установщик: раздел **Releases** справа -> `GWParser_Setup.exe`.

Работает у участников клуба, которые включили «Работаю на команду» в кабинете
GWAd и у кого есть деньги на счету «Поиска клиентов». Вход - кошельком SafePal
и QR-кодом Telegram.
